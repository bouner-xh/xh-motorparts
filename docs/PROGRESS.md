先檢查會不會撞到重複（結果應該是 0 筆）：

```sql
select upper(model_number) as model, count(*) from products group by 1 having count(*) > 1;
```

沒有重複再更新：

```sql
update products set model_number = upper(model_number) where model_number <> upper(model_number);
```

更新後產品網址會變成大寫型號；舊的小寫網址會自動轉址，不會 404。

注意：不使用 cookie 與語言偵測，中文客戶從根網址進來會先看到英文；業務傳連結給中文客戶時請用 `/zh-TW`、`/zh-CN` 開頭的網址。
