# Google Search Console 設定步驟（讓 Google 收錄網站）

目的：讓 Google 知道網站與所有產品頁，買家用料號或品名搜尋時找得到協皇的產品頁；並可查看網站在 Google 的搜尋成效。

- **只要設定一次**。之後新增、修改產品不用再做任何事：網站的 sitemap 會自動更新，Google 會定期回來讀取。
- 所需時間：約 15 分鐘（驗證網域可能要等幾分鐘到幾小時）
- 費用：免費
- 需要：一個 Google 帳號（建議用公司共用的帳號，日後交接方便）、Cloudflare 帳號（網域 DNS 在這裡）
- Google 的畫面偶爾會改版，按鈕名稱可能略有不同；找不到時截圖給工程師。

---

## 第一步：新增網站（網域資源）

1. 打開 <https://search.google.com/search-console>，用 Google 帳號登入。
2. 第一次使用會直接出現「選取資源類型」；已經用過的話，點左上角資源選單 →「新增資源」。
3. 選左邊的 **「網域」**（Domain），輸入：`xh-motorparts.com`
   - 不要加 `https://`、不要加 `www`。選「網域」可以一次涵蓋 `www.xh-motorparts.com`、`xh-motorparts.com` 與 http／https。
4. 按「繼續」。

## 第二步：驗證網域擁有權（DNS 記錄）

畫面會出現「透過 DNS 記錄驗證網域擁有權」。

**做法一：自動驗證（建議，若畫面有提供）**
1. 在說明區的服務供應商下拉選單選 **Cloudflare**。
2. 按「開始驗證」或「Verify」，依畫面登入 Cloudflare 並允許，系統會自動加入記錄。

**做法二：手動加入 TXT 記錄**
1. 在 Search Console 畫面按「複製」，複製一串 `google-site-verification=xxxxxxxx` 的文字。**先不要關掉這個視窗。**
2. 另開分頁登入 <https://dash.cloudflare.com>，點網域 `xh-motorparts.com` → 左側 **DNS** → **Records** → **Add record**。
3. 填寫：

   | 欄位 | 填入 |
   |---|---|
   | Type | `TXT` |
   | Name | `@` |
   | Content | 剛才複製的整串 `google-site-verification=...` |
   | TTL | Auto |

4. 按 **Save**。**不要刪除或修改其他記錄**（網站與 sales@ 收信都依賴現有的記錄）。
5. 回到 Search Console 按 **「驗證」**。
   - 顯示「已驗證擁有權」就完成。
   - 驗證失敗通常是 DNS 還沒更新，等 10 分鐘到 1 小時再按一次「驗證」。
   - 這筆 TXT 記錄之後要**一直保留**，刪掉 Google 會取消驗證。

## 第三步：提交 sitemap

1. 左側選單 →「索引」→ **「Sitemap」**。
2. 「新增 Sitemap」欄位輸入：`https://www.xh-motorparts.com/sitemap.xml`（有些版本只要輸入 `sitemap.xml`）。
3. 按「提交」。
4. 狀態顯示「成功」，並看得到「已找到的網頁」數量，就完成了。
   - 剛提交時狀態可能是「無法擷取」，通常幾小時到一天內會變成「成功」。

## 第四步（選擇性）：要求重要頁面優先收錄

1. 最上方的搜尋框（「檢查『xh-motorparts.com』中的任何網址」）貼上產品頁網址，例如英文產品頁。
   - 產品頁網址：在網站打開產品頁後，複製瀏覽器網址列即可。
2. 等它檢查完，如果顯示「網址不在 Google 服務中」，按 **「要求建立索引」**。
3. 每天能要求的數量有限，只需要做幾個最重要的頁面（首頁、產品目錄、主力產品）。其他頁面 Google 會從 sitemap 自己找到。

## 設定完成後

- **確認收錄情況**：幾天後在 Google 搜尋 `site:xh-motorparts.com`，看收錄了多少頁。
- **成效報表**（左側「成效」）：可以看到網站在哪些關鍵字出現、平均排第幾名、有多少人點擊。建議每月看一次。
- **網頁報表**（左側「索引」→「網頁」）：列出沒有被收錄的網頁與原因；有異常（例如 404）時截圖給工程師。
- **新增管理者**（選擇性）：左下「設定」→「使用者和權限」→「新增使用者」，可以讓其他同事一起看報表。

## 常見問題

- **新增或修改產品後要再提交一次嗎？** 不用。sitemap 會自動更新，Google 會定期回來讀取。很重要的新產品想加快收錄，可以用第四步。
- **多久會出現在搜尋結果？** 通常幾天到幾週。用料號（例如 `2A6-17421-00`）搜尋通常最先找得到；一般品名（例如 `DT125 counter shaft`）要和其他網站競爭，排名需要時間累積。
- **會影響網站或收信嗎？** 不會。第二步只新增一筆 TXT 記錄，不會改到現有設定。
